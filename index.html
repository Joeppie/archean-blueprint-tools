Archean Blueprint Tools v1.13.17

Reverse-engineered craft format + live 3D inspector for Archean workshop blueprints.

  • ★ Open the NEW Blueprint Inspector app (v1.9.2) — the React/TypeScript editor: craft gallery, 3D editor with measurement grid + coordinate readout, live editing, undo, tools, save
  • ▶ Open the 3D viewer/inspector (loads the ISW-241 craft from testdata)
  • Run the regression suite (26 blueprints, format invariants)
  • 🖥 XenonCode — the simulated computer — run craft programs on the dev interpreter (WASM): Hello World, Just-Plane-Easy, Cheap Exploration Plane
  • FORMAT.md · AGENTS.md · NOTICE.md · LICENSE (GPL-3.0)
